
  # 🇱🇷 LIB Too-Much Awards | V1 SuperAdmin Edition

  ## Overview
  A high-fidelity, real-time voting and recognition platform designed for the Liberian student community. 
  This application facilitates the celebration of excellence across Social, Sport, and Academic categories 
  with a focus on transparency, live momentum tracking, and robust administrative control.

  ## Key Features
  - 🗳️ **Dynamic Voting:** 5-star rating system with instant feedback and voter profile persistence.
  - 📈 **Live Zone:** Real-time momentum tracker using sparklines and trend indicators (Rising/Falling/Steady).
  - 🏆 **Wall of Fame:** Automated podium generation for top-ranked candidates across all categories.
  - 🔐 **SuperAdmin Governance:** 
    - Multi-level authentication (SuperAdmin vs. Admin roles).
    - Full CRUD operations for categories and candidates.
    - Global voting deadline management with countdown timers.
    - Admin user management (Create/Remove/Reset passwords).
  - 📊 **Analytics Dashboard:** Comprehensive metrics on voter demographics, engagement levels, and CSV data export.
  - 🌓 **Adaptive UI:** Fluid dark/light mode toggle with a "Bebas Neue" & "Syne" typography stack for a premium aesthetic.

  ## Technical Stack
  - **Frontend:** Vanilla JS, CSS3 (Custom Properties, Flex/Grid), HTML5.
  - **Persistence:** Integrated with `window.storage` for cross-device synchronization and `localStorage` for theme/session state.
  - **Real-time:** Polling-based sync engine to ensure data consistency across multiple concurrent voters.

  ## Setup / Usage
  
  1. Open the Site link in any modern browser.
  2. Explore the various pages
  3. Vote (Home Page): Where u vote for your fav candidates by giving them stars, reactions, and leaving a comment.
  4. Live Zone: A real-time candidate momentum tracker — auto-refresh every 5s, this tells u who's leading the vote race
  5. Wall Of Fame: Tells u the top performers across all categories, and mention their prizes to be won, from 1st to 3rd place.
  6. Admin Pannel: To manage and regulate the voting platform. Adding candidate and monitoring stats
  7. Dashboard: The overall info of the activities on the site
